# Dynamic Checkweigher CW-60 — Service Manual
Machine type: Checkweigher
Manufacturer: Packtech Systems (synthetic manual for demo use)

## 1. Overview
In-line dynamic checkweigher for cartons, accuracy ±0.2 g at 120 packs/min. Load-cell based weigh belt with air-jet / pusher rejector. Verifies missing blisters/leaflets in cartons.

## 2. Alarm / Error Codes
- W01 ZERO DRIFT: load cell contamination, vibration from neighbouring machine, temperature change.
- W03 REJECT CONFIRMATION FAILED: reject bin full, pusher not actuated (check air pressure).
- W05 BELT SPEED MISMATCH: belt slipping, motor encoder fault.

## 3. Troubleshooting — Unstable Weight / False Rejects
1. Check floor vibration; machine must be isolated from cartoner frame. Vibration above 4 mm/s at the weigh table causes false rejects.
2. Re-zero and calibrate with certified test weights (daily).
3. Clean weigh belt; check belt tracking.
4. Shield from air drafts (AC vents).

## 4. Preventive Maintenance
- Daily: calibration check with test weights, reject function challenge test.
- Monthly: inspect belts and rollers, check load-cell cable.
