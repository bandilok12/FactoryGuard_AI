# Self-Adhesive Labelling Machine LB-300 — Service Manual
Machine type: Labeller
Manufacturer: Packtech Systems (synthetic manual for demo use)

## 1. Overview
Wrap-around self-adhesive labeller for round bottles 30-500 ml with thermal-transfer overprinter (batch no., MFG/EXP) and vision OCR verification. Speed up to 300 bottles/min. Conveyor and labelling head driven by servo motors.

## 2. Alarm / Error Codes
- L01 LABEL GAP SENSOR NOT TAUGHT: re-teach gap sensor with new label roll.
- L04 PRINTER RIBBON OUT / RIBBON BREAK.
- L06 OCR MISMATCH: misprint, smudged print, wrong batch data.
- L09 SERVO OVERLOAD: web tension too high, dancer arm stuck.

## 3. Troubleshooting — Misprint / Label Error
1. Clean printhead with isopropyl alcohol; check printhead pressure.
2. Ribbon wrinkling — adjust ribbon tension and peel angle.
3. Line speed too high for printer darkness setting — reduce speed or increase darkness.
4. Wrong batch data — verify batch master data before line clearance (GMP requirement).

## 4. Troubleshooting — Label Skew / Flagging
Check bottle spacing (starwheel/timing screw), wrap belt pressure, label applicator height. Labels flag if bottle surface is wet or oily.

## 5. Troubleshooting — Vibration / Bearing Noise
Conveyor drive bearings and wrap-belt pulleys wear over time. Replace bearings when vibration exceeds 7.1 mm/s or audible noise. Re-tension wrap belt.

## 6. Preventive Maintenance
- Daily: clean printhead, rollers and sensors; verify OCR with challenge test.
- Weekly: check belt wear, lubricate timing screw.
- Monthly: inspect servo cables and bearings.
