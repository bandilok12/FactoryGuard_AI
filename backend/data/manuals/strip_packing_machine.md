# Strip Packing Machine SP-4 — Service Manual
Machine type: Strip Packer
Manufacturer: Packtech Systems (synthetic manual for demo use)

## 1. Overview
Four-track strip packer that seals tablets/capsules between two heated knurled rollers using Alu-foil or poly-laminate. Sealing roller temperature 140-160 °C. Roller pressure set via pneumatic cylinder 4-5 bar. Speed 30-45 cycles/min.

## 2. Alarm / Error Codes
- S01 ROLLER TEMP LOW/HIGH: heater, thermocouple or slip-ring fault.
- S03 FOIL BREAK: foil tension, unwind brake, misaligned guide rollers.
- S05 FEEDER CHUTE BLOCKED: broken tablets, chute vibrator amplitude low.
- S08 CUTTER OVERLOAD: blunt cutter blade, wrong cutting timing.

## 3. Troubleshooting — Poor Seal / Leak
1. Clean knurling with brass brush; residue reduces seal integrity.
2. Verify roller temperatures with contact probe (difference between rollers < 3 °C).
3. Check slip-ring brushes for wear (part SR-BR-04) — intermittent heating causes cold seals.
4. Roller pressure must be 4-5 bar and uniform; replace cylinder seals if pressure drops.
5. High room humidity (> 55%) softens foil laminate — run dehumidifier.

## 4. Troubleshooting — Overheating of Rollers
Heater controller stuck ON or thermocouple de-bonded from roller. Replace thermocouple (TC-K-150), check SSR. Heat-transfer paste must be applied to thermocouple tip.

## 5. Troubleshooting — Vibration and Noise
Worn roller bearings (6204-2RS) or gear backlash. Vibration above 7.1 mm/s requires bearing replacement. Check gear mesh and lubricate with high-temperature grease.

## 6. Cutter & Tool Wear
Replace cutter blades every 200 running hours (part CB-SP4). Blunt blades cause ragged edges, increased torque and cutter overload alarms.

## 7. Preventive Maintenance
- Daily: clean rollers and chutes, check temperatures.
- Weekly: check foil tension, inspect cutter.
- Monthly: inspect slip-rings and bearings, calibrate thermocouples.
