# Automatic Cartoning Machine CT-120 — Service Manual
Machine type: Cartoner
Manufacturer: Packtech Systems (synthetic manual for demo use)

## 1. Overview
Horizontal intermittent-motion cartoner that erects cartons from a magazine, inserts blister strips and leaflets, and closes flaps (tuck-in or hot-melt glue). Rated speed 100-120 cartons/min. Vacuum system: -0.6 to -0.8 bar. Compressed air 6 bar.

## 2. Alarm / Error Codes
- C10 CARTON NOT OPENED: vacuum cups worn, vacuum pump low, carton board warp.
- C12 LEAFLET MISSING: leaflet folder jam, photo sensor dirty.
- C15 PRODUCT MISSING IN BUCKET: upstream blister feed gap; check infeed sensor.
- C20 MAIN DRIVE OVERLOAD: jam in transfer chain, worn chain sprocket, seized bearing.
- C22 GLUE TEMPERATURE LOW (hot-melt units): heater hose fault, set point 160-170 °C.
- C30 LOW VACUUM: vacuum pump filter blocked, worn vane, leaking hose.

## 3. Troubleshooting — Carton Jams / Not Opening
1. Replace suction cups (part VC-20) every 3 months or when torn.
2. Check vacuum level at cup: must be better than -0.6 bar. Clean vacuum filter.
3. Adjust carton magazine guides — carton should slide freely with 1 mm clearance.
4. Check timing of carton pick arm against cam chart (phase 0° ±2°).

## 4. Troubleshooting — High Vibration in Transfer Chain
1. Check chain elongation; replace chain if elongation > 2% (part CH-CT120).
2. Inspect sprocket teeth for hooked wear; replace sprocket set.
3. Lubricate chain with food-grade (H1) oil weekly.
4. Check main gearbox bearings — vibration > 7 mm/s RMS indicates bearing failure.

## 5. Troubleshooting — Overload / Torque High
Overload with high torque usually means mechanical binding. Hand-turn the machine with drive released; locate tight spot. Common: bent pusher rod, foreign body in bucket chain, overload clutch slipping (reset clutch, check spring).

## 6. Preventive Maintenance
- Daily: clean sensors, check vacuum, remove carton dust.
- Weekly: lubricate chains, check suction cups.
- Monthly: inspect overload clutch, check cam followers, tighten frame bolts.
- Quarterly: change gearbox oil, replace vacuum pump filter.

## 7. Safety
Use LOTO. Never reach into the bucket chain while machine is in jog mode. Hot-melt glue can cause burns — wear gloves.
